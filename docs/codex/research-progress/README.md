# 研究进展归档

本目录集中保存 Codex 维护的阶段性研究进展，与项目总报告、单项技术档案和原始实验证据分开管理。
文档应明确记录时间范围、实现范围、技术贡献、验证方法、实验结果和结论边界，以支持后续项目同步、阶段汇报和论文写作。

## 归档约定

- 文件名使用 `<topic>_YYYY-MM-DD.md`，保留报告的截止日期。
- 结论必须区分“机制已实现”、“回归已通过”和“benchmark 已验证”，不以单元测试推导性能提升。
- 实验数据应指向 `../evidence/` 中的原始制品，并记录配置、重复次数、指标口径和统计方法。
- 新增或修订报告后，同步更新本索引、`../README.md`、入口 HTML 和 `../SHA256SUMS.txt`。
