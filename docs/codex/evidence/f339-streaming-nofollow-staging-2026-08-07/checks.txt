- replay permits expected objects across verified staging and verified public corpus

Strict boundary:
- Expected and observed manifest sets remain O(M); F339 is not an O(1)-memory verifier.
- Every valid object still requires complete SHA-256 content reading.
- The valid-manifest benchmark stubs content hashing and is not end-to-end corpus throughput.
- The unexpected-object timing uses a page-cached local file and is fixture-dependent.
- tracemalloc is not process RSS, kernel memory, page cache, or remote-server memory.
- O_NOFOLLOW constrains the final path component; controlled parent roots and a non-Byzantine model remain assumptions.
- No real multi-host, remote-filesystem failover, power-loss, or Byzantine-worker evidence exists.
- No DSE throughput, solver, coverage, bug-discovery, or LAVA-M uplift is claimed.
